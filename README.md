# 🦾 Project F.R.I.D.A.Y. - Lab Sentry System
An air-gapped, offline computer vision perimeter security sentry modeled after Stark Industries lab technology. 

## 🛠️ Features
* **Offline Biometric Profiling:** Tracks spatial matrix telemetry locally to isolate your coordinates as `BOSS` vs. an `UNKNOWN THREAT`.
* **Esc Panic Protocol:** Pressing `Esc` instantly wipes the active terminal grid, throwing the backend monitoring loop into an invisible stealth protocol.
* **Telemetry Archiving:** Automatically captures raw frames of targets after 5 continuous seconds and saves them to an offline security partition.

## 🚀 Terminal Controls
* `Esc` -> Enter Stealth Mode (Closes video grid windows, runs hidden)
* `Spacebar` -> Exit Stealth Mode (Restores visual layout)
* `Q` -> Complete System Power Down
