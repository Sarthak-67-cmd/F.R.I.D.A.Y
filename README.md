# 🦾 Project F.R.I.D.A.Y. — Perimeter Lab Sentry

Welcome to the **F.R.I.D.A.Y. ** offline perimeter tracking node. 

This repository houses an **air-gapped, high-performance computer vision security framework** designed to monitor local terminal coordinates completely offline. By utilizing native digital signal and color-matrix segmentation, it successfully registers authorized personnel while safely logging unknown threats without demanding heavy network dependencies.

---

## 🛠️ Advanced Core Features

*   **Offline Biometric Profiling:** Avoids cloud endpoints entirely. Operates locally by scanning and cross-referencing high-resolution matrix histograms to identify the `BOSS` vs an `UNKNOWN THREAT`.
*   **Tactical Stealth Protocol:** Hitting the `Esc` key triggers an instantaneous GUI purge. The active video windows close immediately, transitioning the terminal into a silent background monitoring engine.
*   **Security Telemetry Logs:** When an unverified entity breaches the tracking area for over 5 continuous seconds, the system automatically runs an extraction snapshot and appends the frame metadata directly to your offline hard drive partition.
*   **Zero-Internet Reliance:** Patched to completely bypass external compiler bugs (`dlib` errors) or firewall connection drops, making it perfectly compatible with cutting-edge **Python 3.14** runtimes.

## 🚀 Lab Control Interface

When the core security terminal window is active, use the following low-latency keyboard shortcuts to control the lab:

| Keystroke | Operational Protocol | Terminal Action |
| :--- | :--- | :--- |
| **`Esc`** | `PANIC STEALTH INITIATION` | Wipes visual monitors; enters background sentry mode. |
| **`Spacebar`** | `DASHBOARD TERMINAL RESTORE` | Re-initializes graphical HUD grid frames and camera window. |
| **`Q` / `q`** | `SAFE LAB POWER DOWN` | Releases optical assets safely and terminates all system threads. |

## 📦 System Architecture & Setup

### 1. Verification Requirements
Ensure your Python environment contains the following baseline packages installed:
```bash
pip install opencv-contrib-python numpy
```

### 2. Biometric Seeding
To train the local sentinel engine to recognize your signature:
1. Create a folder named `authorized_faces` in the project root directory.
2. Place a well-lit, front-facing selfie or profile photograph inside.
3. Save and name the file exactly: **`boss.jpg`**

### 3. Sentry Boot Process
Execute the security node straight from your terminal terminal workflow:
```bash
python F.R.I.D.A.Y.py
```
